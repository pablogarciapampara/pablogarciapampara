## Proyectos

### Asistente de IA para atención al cliente
`Sistema interno en producción`

| | |
|---|---|
| **El problema** | Cientos de emails de clientes en varios idiomas, muchos repitiendo las mismas preguntas sobre pedidos, devoluciones o garantías. |
| **La solución** | Un agente en Python que clasifica cada email, detecta en qué punto está el caso, consulta el pedido real en PrestaShop y prepara la respuesta con las plantillas oficiales en el idioma del cliente. |
| **El detalle** | Las decisiones importantes las toman reglas en código, no el modelo: lo dudoso o delicado siempre pasa a una persona. |

### Automatización de contabilidad y compras
`Sistema interno en producción`

| | |
|---|---|
| **El problema** | Entrada manual de facturas y pedidos de compra, con errores de referencias y mucho tiempo del equipo de finanzas. |
| **La solución** | Procesos automáticos que extraen, validan y registran los documentos en el ERP, y tareas programadas que se ejecutan solas. |
| **El detalle** | Normalización de catálogos y tarifas de proveedores para que las referencias cuadren entre todos los sistemas. |

## Cómo trabajo

- **De principio a fin.** Si una automatización deja pasos manuales, no está terminada.
- **Con control.** La IA propone; las reglas y las personas deciden lo importante.
- **Pensando en quien lo usa.** Una herramienta que nadie entiende no ahorra tiempo.
